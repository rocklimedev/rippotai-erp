# Rippotai document brand rules (all client-facing templates)

Logos (from the official artwork, never redraw/recolour/stretch):
- Full logo (mark + RIPPŌTAI wordmark): `assets/brand/rippotai-logo.png` — cover pages only, centred.
- Monogram (mark only): `assets/brand/rippotai-monogram.png` — inner-page headers, small spaces (min 10 mm tall).
- Wordmark: `assets/brand/rippotai-wordmark.png` — optional, horizontal strips.
- Keep clear space ≥ the height of the gold ellipse around the logo. Logo always on white.

Colours — ONLY these:
- Green #0D3D2F: document title, section headings, table header rows (white bold text), key figures/totals that must stand out.
- Gold #D9B061: thin accent rules / small decorative marks only. Never text, never meaning-carrying.
- Black #1A1A1A: body text. Grey #4D4D4D: labels and secondary text (never lighter).
- Rules #8C8C8C (outer/section), #BDBDBD (inner cell lines only). Fill #F2F2F2 for label columns / totals.
- No other colours (no blues, reds, pastels, status colours) in documents.

Type: Lato. Body 10 pt, tables 9–10 pt, labels min 8.5 pt, H1 22 pt, H2 14 pt, H3 11.5 pt. Line-height 1.4. Numbers right-aligned, tabular.

B&W print test: everything readable when printed in greyscale — no information carried by colour only, no light grey text, header rows dark with white text, borders ≥ #8C8C8C.

Content: do not change document content. Remove decorative filler / AI-sounding helper text that is not document content (e.g. "This beautifully crafted document…", tips, empty-state chatter). Empty optional sections are hidden, not shown as "—" walls.
Layout: A4, 15–18 mm margins, cover page (full logo centred, document name, client/project/date/ref at bottom), inner pages with monogram + doc title + project in header, footer with company line + "Page x of y".
Excel: brand header block (monogram image, title, project, date), header row green fill + white bold, frozen header, sensible widths, number formats ₹ #,##0.00, print setup A4 fit-to-width with repeated header rows, greyscale-friendly.
